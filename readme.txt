== Description ==

Duplicate Post Page is a simple and efficient plugin that allows you to duplicate posts and pages in WordPress with just one click. This plugin is perfect for users who need to create similar content quickly without starting from scratch.

== Features ==

- Duplicate posts and pages effortlessly.
- Retain the original content, title, and settings.
- Lightweight and easy to use.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/pb-duplicate-post-page` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to the post or page you want to duplicate and click the "Duplicate" option.

== Frequently Asked Questions ==

= How do I duplicate a post or page? =
After activating the plugin, go to the post or page list in your WordPress admin. You'll see a "Duplicate" link under each post or page. Click it to create a duplicate.

= Does this plugin work with custom post types? =
Yes, the plugin supports custom post types.

= Can I customize the duplicated content? =
Currently, the plugin duplicates the content as-is. You can edit the duplicated post or page after it's created.
